## ✨ Features & Architecture

### 1. 🏨 Guest Experience & Presentation
- **Hero & Live Booking Widget**: Quick availability check with check-in, check-out date picker, room selector, and guest count.
- **Rooms & Suites Showcase**:
  - *Executive Deluxe Room* (₹1,899 / night)
  - *Super Deluxe AC Room* (₹2,499 / night)
  - *Royal Heritage Suite* (₹3,799 / night)
  - *Presidential Family Suite* (₹4,999 / night)
  - Category filters, photo gallery preview modal, transparent tariff breakdown.
- **Amenities**: 24/7 Generator power backup, passenger elevator (lift), high-speed Wi-Fi, secure parking, 24/7 room service, travel desk.
- **Dining Experience**: Highlighting *Shri Ram Multi-Cuisine Restaurant & Bar* with interactive digital menu highlights (Tandoori, Curries, Thalis, Weekend specials).
- **Banquet & Conference Hall**: 350+ guest capacity for weddings, corporate offsites (NTPC, UPRVUNL, Hindalco), and family celebrations.
- **Location & Distances**: Interactive Google Maps embed with 1-click driving directions and key landmark proximity cards.
- **Google Reviews & Testimonials**: Highlight of 850+ reviews with sub-scores for location, food, hygiene, and staff.

### 2. 🛎️ Customer Booking & Inquiry Flow
- Modal booking system with automatic night calculations and 12% GST breakdown.
- Generates a unique **Booking Reference Code** (`SRI-2026-XXXX`).
- Real-time save to local state and persistent storage.
- Interactive **1-click WhatsApp booking message** pre-formatted with all details directly to the hotel reception (`+91 95986 14567`).
- Direct call dialer and confetti celebration upon confirmation.

### 3. 🛡️ Hotel Staff & Admin Management Portal
- **Dashboard Overview (KPIs)**: Total Bookings, Pending Review Requests, Confirmed Stays, Checked-In Stays, Total Estimated Revenue.
- **Status Management**: 1-click update between `Pending`, `Confirmed`, `Checked-In`, `Completed`, and `Cancelled`.
- **Search & Filter**: Search by customer name, phone, or Booking ID, and filter by reservation status.
- **Walk-in & Phone Reservations**: Integrated form for hotel staff to record offline walk-ins and phone calls.
- **1-Click WhatsApp to Guest**: Staff can message guests on WhatsApp directly from the dashboard.
- **Export to CSV**: Download complete guest reservation records for Excel and hotel accounting.
- **Room Inventory & Rates Tab**: View operational statuses and room rates.
- **Reset / Demo Data**: Button to reload initial realistic sample data anytime.

## 🛠️ Technology Stack

- **Framework**: React 19 + Vite 8
- **Styling**: Tailwind CSS v4 + Custom Luxury Glassmorphism & Gold Gradients
- **Typography**: Google Fonts (*Playfair Display* + *Plus Jakarta Sans*)
- **Icons**: Lucide React
- **Celebration Effects**: Canvas Confetti
- **State Management**: Reactive state persisted with HTML5 Web Storage

## 🚀 Local Development Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/prabhve/demoshriraminternationalantiwebsite.git
   cd demoshriraminternationalantiwebsite
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
